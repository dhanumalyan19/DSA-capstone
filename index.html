DSA Capstone

Huffman Compression Studio

A Huffman encoding project built in Python with a Flask-based browser UI, from-scratch compression logic, tree visualization, entropy analysis, and end-to-end encode/decode workflows.

View GitHub Repository Read Documentation

What’s Included

Compression, decompression, frequency analysis, Huffman tree generation, code tables, and comparison metrics.

How It Runs

The full interactive app runs locally as a Flask project, with source code and setup instructions in the repository.

Clone Command

Use the command below to download the project and run it on your machine.

git clone https://github.com/dhanumalyan19/DSA-capstone.git

Note: This GitHub Pages site is a public landing page for the project. The actual compression app uses a Python Flask backend, so it should be started locally with python main.py unless you deploy the backend to a Python hosting service.
