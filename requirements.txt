# Huffman Compression Studio -- Requirements
#
# This project intentionally uses ONLY the Python standard library:
#   - tkinter        (GUI framework -- ships with standard CPython on
#                      Windows/macOS; on some Linux distros install via
#                      your package manager, e.g. `sudo apt install python3-tk`)
#   - heapq semantics are reimplemented from scratch in core/heap.py
#     for teaching purposes (no external priority-queue library used)
#   - struct, os, time, math, collections -- all standard library
#
# No third-party packages are required to run the application.
# This file is kept (as requested) so `pip install -r requirements.txt`
# completes successfully with nothing to install.
